# Basque Origins Research Project
# Deep-time linguistic analysis of Euskara using aDNA and AI-driven reconstruction

## Project Overview
This project investigates the deep-time origins of the Basque language (Euskara) by combining Ancient DNA (aDNA) analysis with AI-driven linguistic reconstruction. The research tests multiple hypotheses including the "Pre-Proto-Indo-European" sisterhood (Blevins), the "Vasconic Substrate" theory, and the "Nostratic" Super-family hypothesis (15,000 BP).

## Core Objectives
1. Identify deep-time origins of Basque language (Euskara)
2. Test Pre-Proto-Indo-European sisterhood hypothesis
3. Validate Vasconic Substrate theory
4. Evaluate Nostratic Super-family hypothesis (15,000 BP)
5. Merge aDNA analysis with linguistic reconstruction
6. Bypass traditional cognate-only methods
